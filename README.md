# zihoo-update
# صفحه ورود و تأیید کد — زیهو

یک پیاده‌سازی ساده و واکنش‌گرا از صفحه ورود با شماره موبایل و صفحه تأیید کد، طبق طراحی ارائه‌شده.

## ویژگی‌ها
- طراحی مطابق با UI اصلی (عکس‌های مرجع)
- سازگار با موبایل و دسکتاپ
- بدون فریم‌ورک — فقط HTML و CSS
- کدهای تمیز و قابل فهم

## فایل‌ها
- `index.html` — صفحه ورود شماره موبایل
- `styel.html` — صفحه ورود کد تأیید
- `-test.css` — استایل صفحه ورود
- `-test.css` — استایل صفحه تأیید

## نحوه استفاده
فایل‌ها را در یک پوشه کنار هم قرار دهید و `login.html` را در مرورگر باز کنید.


> ✨ ساخته‌شده با عشق برای یادگیری و نمایش مهارت‌های فرانت‌اند
